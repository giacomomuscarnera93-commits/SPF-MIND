🐭 Breeding cages / Stock cages
  • 1Anibio → Animal list → export DOB / Gene / Sex / In breeding
  • 2Import CSV in either tab — one file, no positions needed
Cages are matched by cage code — updated in place, new ones added, nothing ever deleted automatically. The In breeding column decides whether a cage lands in Breeding or Stock; if that column is missing, everything goes to the tab you imported into. Litter history comes from the Pups tab, not from this import — add pups there with a cage code to feed a breeding cage's log.
